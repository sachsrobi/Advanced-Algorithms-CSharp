# Advanced Algorithms in C#

A university coursework project implementing three optimization algorithms in C#, with a focus on heuristic search, problem-solving, and visualization.

### Algorithms

- **Hill Climbing with Random Restart** – Finding a minimum-area bounding quadrilateral for a set of points.
- **Tabu Search** – Approximating solutions to the Traveling Salesperson Problem (TSP).
- **Particle Swarm Optimization (PSO)** – Finding minima of mathematical functions using a particle swarm.

### Features

- Algorithm implementation based on course materials
- Performance measurements and iteration tracking
- Visualization of optimization results
- Randomly generated test data

**Technologies:** C#, .NET, System.Drawing

**Documentation:** Detailed Hungarian documentation is included in the repository, describing the algorithms, implementation, and test results.
